description=Browse the SemanticGIS (SPHERE) data network and load its WFS, WMS and WMTS services
about=SemanticGIS organises Danish and European geospatial data as a network of spheres, twigs and leaves: each leaf is a question you can ask of the data (for example "Which nature protection designations apply here?"). This plugin lets you browse that network or search it by question, and adds the services behind each leaf as layers. Every layer is tagged with the leaf and dataset it came from. The catalogue is published at semanticgis.org and checked against the live services.

changelog=0.7.15 New tool: Vector table › Renumber feature ids (fid). Gives every feature a unique fid, so a layer saves as a GeoPackage again after Multipart to singleparts and similar tools ('UNIQUE constraint failed').
    0.7.14 SemanticGIS tools in the Processing Toolbox, grouped by what they do. First tool: Raster analysis › Tabulate area (legend labels), the pixels or area of each class of a categorical raster (land use) inside each polygon, one column per legend label.
    0.7.13 Fix: GeoDanmark WFS layers (e.g. Bykerne) failed with 'Received feature geometry has Z values but the layer type (Polygon) does not'. WFS layers now read one feature first to learn the real geometry type (QGIS's 'Force initial GetFeature').
    0.7.12 WFS layers that QGIS opens without geometry (Datafordeleren's DAGIM, e.g. Kommuneinddeling 1:10.000) are shown as 'no geometry in QGIS' and not offered as working; where the same data exists in DAGI WFS entiteter, that layer is preferred instead.
    0.7.11 Fix: layers added by the plugin left QGIS's coordinate systems broken about 30 s later (layers drawn unprojected, saved files with 'Undefined SRS', GeoParquet export crashing, processing exports without CRS). Layers built in the background now get a CRS made on the main thread, with QGIS's CRS cache cleared.
    0.7.10 A project without a coordinate system (e.g. after opening a file without one) gets the CRS of the first layer the plugin adds, so layers in different CRSs line up instead of being drawn kilometres apart.
    0.7.9 Join: a reference is not offered when all its matches are also matched by a better one in the same column (municipality codes 101–400 are also rode numbers).
    0.7.8 Join: levels count as mixed only when their codes are separate, so rode codes that equal municipality codes (101, 147 …) no longer make a rode table look mixed. Københavns Kommune's bydele, lokaludvalg, kvarterer and roder are in the catalogue as reference units.
    0.7.7 Join: a statistics table that mixes levels in one column (e.g. Københavns Kommune's KKBEF8: districts, local committees and quarters) offers every level, each joining its own rows; number columns whose values happen to look like unit codes are no longer offered.
    0.7.6 SSL errors with Datafordeleren/Dataforsyningen: the plugin adds the root certificates they need (Sectigo R46, ISRG Root X1/X2) to QGIS's authorities when QGIS does not trust them; Settings › Test connections… says what is wrong (missing root, HTTPS inspection by antivirus, wrong clock, no connection) with a report to copy. Fix: subset layers send their filter as POST (Danmarks Miljøportal now blocks filters in URLs).
    0.7.5 Subsets: datasets whose realisation names a categorical attribute show 'Subsets by …' (e.g. Beskyttede naturtyper by habitat type); double-click loads the same WFS layer filtered on the server. Derived datasets say what they were derived from, how and as of when.
    0.7.4 Fix: in some QGIS installations Datafordeleren's WMTS basemaps (Skærmkort) failed with 'Cannot calculate extent' when built in the background; a layer that fails there is now tried once more on the main thread. Full errors go to Log Messages › SemanticGIS.
    0.7.3 Fix: the plugin's entries (Copy attribution, Copy attributions of all layers) now appear on the Layers panel's right-click menu; QGIS's signal is contextMenuAboutToShow.
    0.7.2 Updates through QGIS: the plugin adds its update channel to QGIS's plugin repositories, so Plugins > Manage and Install Plugins offers new versions.
    0.7.1 The panel footer shows the plugin's name and version (SemanticGIS 0.7.1); the SPHERE index version is in its tooltip.
    0.7.0 Keys per access profile (Datafordeleren, Dataforsyningen, CARTO; more come with the catalogue): added to requests as they are sent, never saved in layers or projects; optionally encrypted with the QGIS master password; 🔒/🔑 markers and Set/How to get a key on the right-click menu. CARTO basemaps work with your own CARTO key.
    0.6.0 Attribution: every layer added gets its credit line (layer attribution, metadata rights, so map_credits() works in layouts); right-click Copy attribution on datasets, services and basemaps; Copy attributions for the map (panel button and the Layers panel's right-click menu). Datafordeleren registers open their semanticgis.org pages.
    0.5.2 Basemaps that serve a placeholder image (e.g. CARTO without an API key) are no longer offered as working.
    0.5.1 Fix: WCS layers are requested in a CRS the coverage supports (empty cells when the project was in Web Mercator, e.g. after adding OSM); QGIS reprojects.
    0.5.0 WCS layers (e.g. the DHM elevation model as real heights); Datafordeleren's registers and services under Datasets by Collection and on leaves they realise; Datafordeleren twins preferred over Dataforsyningen.
    0.4.1 Fix: the panel no longer disappears when docked as a tab with other panels; the toolbar button brings a tabbed-away panel to the front.
    0.4.0 Basemaps: Danish (Skærmkort, orthophotos, målebordsblade, shaded relief) and international (OpenStreetMap, OpenTopoMap, CARTO, Esri, EOX Sentinel-2) basemaps, added under your data with attribution.
    0.3.3 Preferred services: providers ranked by the knowledge base (Datafordeleren before Dataforsyningen), ★ marks the preferred service, double-click a dataset to add it; realisations in priority order.
    0.3.2 Dataforsyningen layers work in QGIS 4 (HTTP/1.1 workaround for the API gateway); Datafordeleren via API key on the modernised wms./wmts./wfs. hosts; credentials only from Settings.
    0.3.1 Every node has 'Show web page' on right-click; twig titles from their pages; empty entry points explain why.
    0.3.0 Six entry points like the website: Classical Classifications, Collection Methods, Datasets by Collection, Datasets by Owner, SPHERE and Reference Framework. All harvested datasets browsable by owner; reference geometries (NUTS, LAU) loadable at each scale; search covers datasets.
    0.2.0 Join a table to reference units (NUTS, LAU): the join is detected from the table's IDs or names, and only the needed geometries are fetched at the chosen scale.
    0.1.0 First version: browse and search the SPHERE network, add verified WFS/WMS/WMTS layers.
